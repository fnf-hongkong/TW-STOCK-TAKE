盤點差異填寫工具

上傳盤點公司的 Variance Report by Barcode → 逐筆填寫差異原因與照片 → 匯出檔案 E-mail 回傳
使用步驟
  1. 選擇「店櫃」，「盤點日期」會自動帶入該店預定的盤點日（如實際日期不同可自行修改）。
  2. 上傳盤點公司提供的 Variance Report by Barcode（CSV）— 系統會自動列出所有差異（VAR≠0）品項。
  3. 逐筆選擇差異原因；選「其他」需自行填寫原因。漏盤 / 多盤請務必附上照片（同貨號所有數量）。
  4. 原因會依差異正負自動限制：確定短少 / 漏盤只能選在負差異，確定有多 / 多盤只能選在正差異（不符的選項會鎖住）。
  5. 選尺寸/顏色正負對消時，只能從同 STYLE 且反向差異的品項下拉選擇對消對象；系統會即時稽核每個 STYLE 的對消合計是否為 0。
  6. 全部填完 → 點右下角匯出檔案 → JSON 會自動下載、並跳出列印視窗 → 目的地選另存為 PDF → 將 JSON ＋ PDF 兩個檔 E-mail 回傳給 Logistics（Silvia）。
